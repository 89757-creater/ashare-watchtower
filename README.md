数据源全部免费公开（腾讯行情、新浪财经），无需 API Key。

## 安装

把本仓库作为一个 Skill 目录放入 Kimi Work 技能目录（如 `~/.kimi/skills/ashare-watchtower`），然后对 Kimi 说：

> 帮我搭建 A 股监控看板，持仓 588170，600 份，成本 1.059

Agent 会按 SKILL.md 引导完成配置、Widget/Automation 创建、接线与看板放置。
